1. Authentication

All API requests to Upipay require custom headers to authenticate the merchant account. You must pass your **Key ID** (`x-key-id`) and an HMAC-SHA256 **Signature** (`x-signature`).

Generating the Signature

  1. Sort: Arrange all keys in your JSON request alphabetically.
  2. Filter: Remove any keys containing empty strings, null values, or empty arrays/objects.
  3. Concatenate: Join values with the | character.
  4. Hash: Compute the HMAC-SHA256 hash using your **Key Secret**.
// Example in Node.js
const crypto = require('crypto');

function generateSignature(payload, secret) {
    // 1. Sort and filter
    const sortedKeys = Object.keys(payload).sort();
    const values = [];

    sortedKeys.forEach(key => {
        if (payload[key] !== null && payload[key] !== '') {
            values.push(payload[key]);
        }
    });

    // 2. Concatenate
    const strToSign = values.join('|');

    // 3. Hash
    return crypto.createHmac('sha256', secret)
                 .update(strToSign)
                 .digest('hex');
}

2. Create a Payment Request

Use this endpoint to generate a unique checkout link for your customer. The link defaults to a 15-minute lifespan.

POST https://api.upeeqst.com/api/v1/payment/requests

Request Payload Example

{
    "amount": 500.00,
    "currency": "INR",
    "order_id": "ORD-987654",
    "customer_email": "user@example.com",
    "customer_phone": "9876543210"
}

Success Response Example (200 OK)

{
    "status": "success",
    "data": {
        "service_request_id": "req_a1b2c3d4e5f6",
        "payment_link": "https://pay.upipay.com/req_a1b2c3d4e5f6",
        "expires_in": 900
    }
}

3. Webhooks

Register your Webhook URL in your Connect-M settings to listen for status changes. When a customer pays, Upipay will send a POST request containing the service_request_id and the new status (e.g., PAID).
